# Code of Conduct

## Our standard

Be respectful, constructive, inclusive, and professional. Assume good intent,
explain technical reasoning, accept feedback, and focus discussion on improving
the project and protecting users' data.

Harassment, discrimination, personal attacks, trolling, sexualized content,
threats, spam, and publishing another person's private information are not
accepted.

## Privacy

Do not post personal or customer information when asking for help. This includes
contacts, phone numbers, conversations, attachments, credentials, database dumps,
server addresses, and identifying logs. Maintainers may remove content that risks
someone's privacy or security.

## Scope

This code applies to issues, pull requests, discussions, and other spaces managed
by this repository. Participation in Chatwoot's Discord or GitHub organization is
also governed by Chatwoot's own community guidelines and moderation team.

## Reporting

Report repository conduct concerns through the issue tracker without including
private information. If public reporting would expose a person or a security
issue, use GitHub's private vulnerability reporting option for this repository.

Maintainers may edit or remove contributions and may temporarily or permanently
restrict participation when necessary to protect the community.
